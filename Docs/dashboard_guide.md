
# Dashboard Guide

The Power BI dashboard provides operational insights into refrigerated container performance and shipment health.

## Page 1 – Operational Monitoring

- KPI Cards
- Temperature Trend
- Container Status Distribution
- Fruit-wise Shipment Distribution
- Average Temperature by Fruit
- Operational Insights

## Page 2 – Logistics & Shipment Analysis

- Shipment Distribution by Origin
- Shipment Distribution by Destination
- Container Status by Origin
- Environmental Summary
- Operational Insights

The dashboard enables users to monitor shipment conditions, identify high-risk containers, and analyze logistics performance through interactive visualizations.
