
# Project Overview

## AtmoSync – Micro-Climate Arbitrage Analytics

AtmoSync is a real-time supply chain analytics project designed to monitor refrigerated agricultural shipments using IoT sensor data. Traditional logistics systems primarily rely on estimated transit times and macro-weather forecasts, making it difficult to detect hyper-local environmental changes inside individual shipping containers. These unnoticed changes can accelerate spoilage, reduce product quality, and result in significant financial losses.

The goal of AtmoSync is to simulate an intelligent cold-chain monitoring system capable of detecting abnormal environmental conditions such as temperature drift, humidity fluctuations, and equipment health issues before they impact the quality of perishable goods. By combining IoT-generated sensor data with analytics and visualization, the project provides actionable insights that support timely operational decisions.

## Problem Statement

Traditional supply chain analytics fail to monitor real-time micro-climate conditions inside refrigerated shipping containers. Sudden changes in temperature or humidity during transit can degrade agricultural commodities before they reach the market, leading to increased spoilage and economic loss.

## Solution

AtmoSync addresses this challenge by building a data-driven analytics pipeline that:

- Simulates IoT sensor data from refrigerated containers.
- Collects environmental and shipment telemetry.
- Performs exploratory data analysis to understand shipment behavior.
- Engineers business-focused features such as risk level and battery health.
- Uses SQL to generate operational insights.
- Presents interactive dashboards for monitoring container performance and logistics.

## Key Features
